# Release Notes

บันทึกการอัปเดตที่ **ส่งให้ลูกค้าอ่าน** หนึ่งไฟล์ต่อหนึ่งเวอร์ชัน (`v<x.y.z>.md`)
ไฟล์ในโฟลเดอร์นี้คือต้นฉบับ ส่วน Google Doc ที่ลูกค้าเปิดดูคือสำเนาที่อัปโหลดขึ้นไป

## กฎการเขียน

- ภาษาไทย เขียนจากมุมผู้ใช้และเจ้าของร้าน ไม่ใช่มุมคนเขียนโค้ด
- **ห้ามมีชื่อไฟล์ ชื่อตาราง ชื่อฟังก์ชัน path หรือชื่อ environment variable**
- เรื่องความปลอดภัย เขียนว่าปิดช่องอะไรไปแล้ว ห้ามอธิบายวิธีที่ช่องนั้นถูกใช้โจมตี
- แยกงานที่ผู้ใช้เห็นออกจากงานหลังบ้านที่มองไม่เห็นเสมอ ลูกค้าจ่ายเงินให้ทั้งสองอย่าง

## โครงเอกสาร

`v0.4.0.md` เป็นฉบับสรุปภาพรวมทั้งระบบเพราะเป็นฉบับแรก
ฉบับถัดไปใช้หัวข้อชุดเดียวกันแต่ลงเฉพาะสิ่งที่เปลี่ยนในรอบนั้น:
ของใหม่ / แก้ไขและปรับปรุง / งานหลังบ้าน / สิ่งที่กำลังทำต่อ

ขั้นตอนตอนออกเวอร์ชันใหม่อยู่ใน `snailshop.md` หัวข้อ "Cut a release"
